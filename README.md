# AWS-Cloud-Portfolio

This repository contains a collection of AWS cloud engineering projects designed to demonstrate hands-on experience with cloud infrastructure, identity, networking, automation, and monitoring.

Each project includes:

- Architecture diagrams
- Deployment notes
- Screenshots
- Infrastructure-as-Code (when applicable)
- A summary of what was learned

---

## 📁 Project Index

### 01 — Account Foundation (AWS Landing Zone)
Establishes a secure multi-account baseline using AWS Organizations, SCPs, IAM guardrails, and foundational security controls.

### 02 — IAM & Identity
Covers IAM roles, policies, trust relationships, Identity Center (SSO), MFA enforcement, and least-privilege patterns.

### 03 — VPC Networking
Implements a production-style VPC with public/private subnets, NAT gateway, route tables, security groups, NACLs, and optional Transit Gateway.

### 04 — Monitoring & Logging
Builds CloudWatch dashboards, metrics, alarms, logging pipelines, AWS Config rules, and integrates GuardDuty + Security Hub.

### 05 — Automation & IaC
Demonstrates automation using Terraform, EventBridge, Lambda, and reusable IaC modules.
